# CPU Grid — UI (Next.js)

Frontend for **CPU Grid – Distributed Monte Carlo Traffic Simulation**.  
This is the UI layer of the project (Next.js + Tailwind). The backend (Master/Worker/Client) is implemented in Java (RMI).

> Status: UI is currently focused on landing/auth pages and layout. Backend integration can be added later.

---

## Tech Stack

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**
- (Optional) `lucide-react` icons / animation libs (if installed)

---

## Prerequisites

Install:

- **Node.js 18+** (recommended 18 LTS or 20 LTS)
- **npm** (comes with Node)

Check versions:

```bash
node -v
npm -v
```
